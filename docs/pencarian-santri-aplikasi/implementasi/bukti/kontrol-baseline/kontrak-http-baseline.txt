[lulus] Akun Keamanan, admin, dan murobi memperoleh token API

=== C-1 /keamanan/izin?q= ===
[lulus] Daftar tanpa q berhalaman (42 halaman, 1040 baris)
[lulus] Ada santri yang izinnya hanya di halaman > 1 (kasus lintas halaman)
[gagal] q NIS: hasil = oracle saringan seluruh halaman (5 baris), memuat santri dari halaman > 1
[gagal] q nama (huruf besar): hasil = oracle saringan seluruh halaman (5 baris), memuat santri dari halaman > 1
[gagal] q potongan nama: hasil = oracle saringan seluruh halaman (1000 baris), memuat santri dari halaman > 1
[gagal] Ringkasan memakai saringan q yang sama; filter q dikembalikan
[lulus] NIS santri nonaktif tidak membuka izinnya (cakupan tidak melebar)
[lulus] q NIS + asal Wali digabung (oracle SQL 1, memuat pengajuan wali); peran tetap Keamanan

=== C-2 validasi q ===
[gagal] q array → 422
[gagal] q 101 karakter → 422
[gagal] `%` dicari harfiah, bukan wildcard
[gagal] `_` dicari harfiah, bukan wildcard
[gagal] q spasi saja = tanpa saringan (filter q null)
[lulus] Admin tanpa penugasan Keamanan tetap 403 dengan q

=== C-3 /keamanan/pelanggaran|konseling?q= NIS ===
[gagal] Keamanan pelanggaran: q NIS setiap santri terlihat = oracle saringan daftar sendiri (2 santri)
[gagal] Keamanan konseling: q NIS setiap santri terlihat = oracle saringan daftar sendiri (1 santri)
[lulus] Kasus Rahasia tidak muncul lewat pencarian NIS; angka = baris terlihat

=== C-4 /v3 daftar pembinaan aplikasi ===
[gagal] admin pelanggaran: q NIS/nama = oracle saringan seluruh daftar akun sendiri (5 baris, 3 santri)
[gagal] admin kasus: q NIS/nama = oracle saringan seluruh daftar akun sendiri (2 baris, 2 santri)
[gagal] murobi pelanggaran: q NIS/nama = oracle saringan seluruh daftar akun sendiri (4 baris, 2 santri)
[gagal] murobi kasus: q NIS/nama = oracle saringan seluruh daftar akun sendiri (1 baris, 1 santri)
[lulus] Murobi: NIS santri di luar cakupan tidak membuka pelanggarannya

=== C-5 audit ekspor tanpa kata kunci ===
[lulus] Ekspor admin dengan q berhasil dan memuat baris santri yang dicari
[gagal] Audit ekspor: q hanya penanda true, tanpa nama santri
