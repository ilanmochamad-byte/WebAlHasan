# cPanel — MENUNGGU PRODUKSI

Sesi implementasi tidak deploy, tidak migrasi produksi, tidak mengubah kanal/cron, tidak membersihkan produksi. Operator melanjutkan hanya sesudah audit Claude Code dan izin Human Developer. Risiko smoke Fase 3 §6 serta prosedur data smoke tetap terbuka sesuai [panduan Fase 4](../phase-v3-4/panduan-uji-fisik-dan-cpanel.md).

1. Backup dan restore rehearsal, manifest/hash commit, preflight dan prosedur [migrasi/rollback](migrasi-verifier-rollback.md). Validasi PHP ekstensi mysqli, hosting MySQL/MariaDB, indeks dan query planner. Gunakan akun dan santri smoke sintetis yang sudah disetujui operator; tidak menyalin bisnis nyata ke provider/DB uji.
2. Empat peran pada desktop/375 px: cakupan laporan HTML, cetak/Simpan PDF, CSV; filter santri/kelas/kamar/periode/kategori/tingkat/status/poin/pembimbing/murobi/tindak lanjut. Uji >10.000 hasil pada salinan staging, bukan fixture massal produksi. Tidak ada pemotongan diam-diam atau isi rahasia. Rekonsiliasi ledger/agregat, referensi, status, publikasi/outbox; selidiki bukan hapus otomatis.
3. Selesaikan smoke Fase 3 §6 yang tertunda: alur kasus/sesi, Rahasia, revisi, transaksi/outbox, lampiran dan akses silang. Simpan bukti operator tersanitasi. Jangan mengubah statusnya menjadi lulus hanya berdasarkan regresi lokal.
4. Cron V2 yang sudah ada `notifikasi_worker.php --kanal=push` tetap menurut interval operator yang tercatat. Verifikasi cron otomatis, retry/backoff dan polling receipt sampai final; baca `php bin/v3_push_receipts.php`. Tool ini baca saja, bukan pengirim/poller baru. Push produksi tetap ON, WhatsApp OFF. Adapter fake bukan bukti receipt produksi. Receipt yang masih pending dicatat dan ditelusuri sesuai batas provider.
5. Dry-run retensi, review ID/jumlah, lalu batch purge setelah izin operator. Jangan mencampur pembersihan pratinjau dengan pembersihan data smoke. Publikasi terbit/riwayat/audit tidak dihapus.
6. Pembersihan smoke produksi memakai prosedur Fase 3–4 dan persetujuan operator: inventaris ID smoke, relasi/ledger/audit/outbox, backup, arsip/pembatalan/penarikan beralasan bila sesuai. Tidak ada DELETE massal maupun menonaktifkan FK; simpan sejarah wajib. **MENUNGGU PRODUKSI** sampai bukti tindakan ada.
7. Bukti performa staging setara hosting 1.000 data sintetis dan list <2 detik; bukti lokal bukan penggantinya. Catat waktu, jumlah, indeks, lingkungan dan hasil aktual.
