
=== S-1. Migrasi 030 ===
[lulus] 030 adalah migrasi terakhir dan memiliki pasangan rollback
[lulus] Migrasi tanpa DROP/DELETE/TRUNCATE/UPDATE/INSERT/RENAME (selain aturan ON DELETE kunci asing)
[lulus] ALTER hanya pada izin_pengajuan
[lulus] Setiap perubahan dibungkus pemeriksaan INFORMATION_SCHEMA (idempoten)
[lulus] ENUM: lima nilai V2 berurutan di depan, empat tahap V7 di ujung
[lulus] Asal bawaan Pengurus; CHECK asal ↔ wali ↔ tahap
[lulus] Tabel penetapan: versi berurutan, InnoDB

=== S-2. Rollback 030 ===
[lulus] Penjaga data (CHECK pada tabel sementara) dijalankan sebelum perubahan skema
[lulus] Penjaga menghitung baris wali/tahap V7, penetapan, dan klaim idempotensi V7
[lulus] Rollback tanpa DELETE/UPDATE dan hanya melepas tabel V7
[lulus] ENUM dikembalikan ke lima nilai V2

=== S-3. Layanan ===
[lulus] Buat: kunci akun → klaim idempotensi → hak wali (kunci baca) → kunci santri → tahun → benturan → routing → sisip → riwayat → selesai → audit
[lulus] Penetapan: admin → kunci akun → klaim → kunci pengajuan → versi → pembimbing sah (kunci baca) → ubah bersyarat versi → riwayat penetapan → riwayat → audit
[lulus] Ubah penetapan memakai versi optimistis + status; transaksi READ COMMITTED
[lulus] Sisip pengajuan wali: pengurus_id dan murobi_guru_id NULL (murobi belum menerima)
[lulus] Audit pembuatan tanpa alasan/catatan/tanggal; riwayat pembuatan tanpa alasan izin
[lulus] Layanan/repositori/router V7 tidak membaca variabel global request
[lulus] Fase 1 tidak mengirim notifikasi (Fase 3); WhatsApp tidak disentuh
[lulus] Pembimbing sah: penugasan aktif, tahun aktif, akun pengurus aktif
[lulus] Di luar hak baca/anak lain → 404
[lulus] Wali lain: proyeksi ringkas tanpa riwayat
