Perubahan suite uji lama untuk optimasi Android Google Play (21 November 2026, Claude Code).
Tidak ada assertion yang dilonggarkan atau dihapus; perilaku saat METRO diisi (dev client) tidak berubah.

1. Mode RILIS (peluncuran build Release dengan bundel tertanam, tanpa Metro/dev client)
   uji-redesain-v2-fase1-android.mjs, uji-redesain-v2-fase2-android.mjs, uji-redesain-v2-fase3-android.mjs,
   uji-profil-impor-f2-android.mjs:
     - penjaga awal: METRO wajib localhost, KECUALI RILIS=1 dengan METRO kosong;
     - bukaApp(): bila METRO kosong, `am start -a MAIN -c LAUNCHER -n <paket>/.MainActivity`
       (setara ketukan ikon) menggantikan URL dev client.
   uji-redesain-v2-fase4-android.mjs (sudah punya mode rilis): `monkey -p … LAUNCHER 1` diganti
     `am start … MAIN/LAUNCHER -n <paket>/.MainActivity` karena monkey gagal (exit ≠ 0) pada
     emulator Android 16 Play image.

2. uji-profil-impor-f2-android.mjs — penanda/pencari elemen yang tertinggal sejak tindak lanjut redesain
   TL-02/TL-03 (suite Android ini tidak termasuk putaran native tindak lanjut 13 November):
     - bukaProfil(): penanda Profil ditambah subjudul "Identitas, penugasan, dan pengaturan akun"
       (pada teks 2,0× "Perangkat & push/Data diri/Edit profil" berada di bawah lipatan layar),
       dan gulir ke atas sebelum mengetuk kartu "Buka profil" (halaman Beranda dapat tertinggal
       tergulir oleh langkah sebelumnya pada teks 2,0×);
     - Edit profil termuat: penanda ditambah "Ubah foto" (TL-02 memindahkan "Foto profil" ke lembar bawah);
     - sesudah Simpan perubahan: buka "Data diri" sebelum mencari nilai "Garut Native" (TL-03);
       assertion DB tempat lahir tetap sama;
     - pemeriksaan sisa cache cache/ImagePicker memakai `run-as` yang hanya ada pada APK debuggable;
       pada RILIS=1 dicetak [lewati] (TIDAK dihitung lulus). Saat METRO diisi, assertion tetap berjalan;
     - kalimat Photo Picker: ditambah varian "can only access the photos you select" (teks modul
       Photo Picker image Android 15 google_apis; makna sama). Putaran API 35 dijalankan SEBELUM
       penambahan ini dan dicatat apa adanya 23/1.
