=== C. Isi menurut peran dan angka = API ===
[lulus] Menu petugas: 8 ubin (lengkap)
[lulus] Menu petugas: tanpa angka (respons akses tidak memuat angka; tanpa angka karangan)
[gagal] Kepala profil petugas: Saldo Rp130.000 · Sisa tagihan Rp180.000 · Transfer menunggu Rp15.000 = API
[lulus] Petugas melihat setoran transfer menunggu beserta referensinya
[lulus] Tab segmen Ringkasan / Tagihan / Tabungan
[lulus] Tab Tagihan: hanya bagian tagihan
[lulus] Tab Tabungan: hanya bagian tabungan
[lulus] Mutasi: 5 baris bernominal bertanda sesuai arah API
[lulus] Kuitansi transfer menunggu: panel "Menunggu verifikasi" berikon jam, bukan "Pembayaran sah"
[lulus] Kuitansi sah: panel "Pembayaran sah" + kartu kuitansi bergaris putus
[lulus] Laporan bulan ini: grafik tidak tampil (seri 1 bulan)
[lulus] Laporan tahun ini: 11 batang = 11 bulan seri dari server
[lulus] Laporan: kartu sorot "Penerimaan kas baru" Rp220.000 = API
[lulus] Target sentuh: seluruh kontrol terlihat pada 19 layar ≥ 44 pt (0 di bawah)
[lulus] Menu admin: 7 ubin hanya baca, tanpa penerbitan
[lulus] Rincian santri admin: tanpa tombol mutasi (server tetap memutuskan)
[lulus] Rincian tagihan admin: tanpa bilah tindakan dan tanpa ⋯
[lulus] Menu orang tua: kartu sorot saldo + sisa tagihan per anak = API (Rp130.000/Rp180.000, Rp0/Rp0)
[lulus] Rincian anak (orang tua): strip Saldo · Sisa tagihan tanpa transfer menunggu/referensi
