=== 3. Otorisasi dan idempotensi ===
[lulus] `mode` dari request hanya boleh mempersempit, tidak pernah menaikkan cakupan
[lulus] Seluruh operasi API perizinan melewati penerjemah error tunggal
[lulus] Pemetaan status HTTP memuat 403 => 'FORBIDDEN'
[lulus] Pemetaan status HTTP memuat 404 => 'NOT_FOUND'
[lulus] Pemetaan status HTTP memuat 409 => 'CONFLICT'
[lulus] Pemetaan status HTTP memuat 'VALIDATION_FAILED'
[lulus] Mutasi create() meneruskan idempotency key ke lapisan domain
[lulus] Mutasi decide() meneruskan idempotency key ke lapisan domain
[lulus] Mutasi assign() meneruskan idempotency key ke lapisan domain
[lulus] Mutasi cancel() meneruskan idempotency key ke lapisan domain
[lulus] Mutasi correct() meneruskan idempotency key ke lapisan domain
[lulus] Retry create/keputusan membalas 200 (pemutaran ulang), bukan 201 baru
[lulus] Lapisan API tidak pernah menulis langsung ke basis data
[lulus] Capability murobi tetap berasal dari penugasan aktif, bukan role terpisah
[lulus] Login pengurus/orang tua hanya diizinkan bila relasi masternya aktif
[lulus] Aturan login admin dan guru V1 tidak berubah
