=== U-1. Migrasi 029 ===
[lulus] Satu CREATE TABLE IF NOT EXISTS bsa_setoran_transfer
[lulus] Tanpa DROP/DELETE/UPDATE/ALTER/INSERT terhadap tabel mana pun (027/028 tidak diubah)
[lulus] Nominal BIGINT, tanpa tipe pecahan
[lulus] InnoDB, 6 kunci asing, 5 CHECK
[lulus] Sah ⇔ satu baris ledger (unik); kunci idempotensi unik per pencatat; tolak wajib beralasan

=== U-2. Rollback 029 ===
[lulus] Rollback melepas tepat satu tabel 029
[lulus] Penjaga data (antrean transfer, jenis ledger Fase 3, pembayaran dari tabungan) dijalankan sebelum DROP

=== U-3. Layanan dan repository ===
[lulus] Tanpa float, pembulatan, atau literal pecahan di kode layanan/repository BSA
[lulus] Layanan/repository tidak membaca superglobal
[lulus] Repository tabungan: satu pintu prepare + bind_param; query langsung hanya untuk snapshot baca rekonsiliasi
[lulus] Kunci/deadlock → 409, CHECK → 422 (sama dengan BsaRepository)
[lulus] Ledger tabungan tidak pernah di-UPDATE; tidak ada DELETE pada tabel BSA
[lulus] Setoran transfer menunggu hanya menulis antrean 029, tidak menyentuh ledger/saldo
[lulus] Hanya tunai atau transfer yang dinyatakan sudah diperiksa yang sah seketika

=== U-4. Urutan kunci, cakupan sebelum replay, atomisitas ===
[lulus] setoranMenunggu: penugasan (kunci baca) → klaim → cakupan/status santri → baru replay
[lulus] putusSetoran: penugasan (kunci baca) → klaim → cakupan/status santri → baru replay
[lulus] koreksi: penugasan (kunci baca) → klaim → cakupan/status santri → baru replay
[lulus] Verifikasi: setoran transfer (tulis) → akun (tulis) → ledger → tandai sah, satu transaksi
[lulus] Koreksi: akun dikunci, pembalik merujuk asal, debit tagihan ditolak (lewat pembatalan), saldo tidak boleh negatif
[lulus] Bayar dari tabungan: lewat mutasiTagihan (tagihan dikunci dulu) → akun → debit ledger → pembayaran merujuk debit → terbayar + kuitansi, satu transaksi
[lulus] Bayar dari tabungan: persetujuan eksplisit wajib; verifikasi sisa (dikurangi transfer menunggu) dan saldo
[lulus] Pembatalan pembayaran dari tabungan mengembalikan saldo di transaksi yang sama
[lulus] Cerminan saldo akun diperbarui bersyarat saldo lama yang dikunci
