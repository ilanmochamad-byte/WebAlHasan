=== T-4. Worker Push dan tautan ===
[lulus] Worker: pemeriksaan ulang penerima/keadaan → teks dari katalog → data hanya penunjuk → sakelar dibaca ulang → provider
[lulus] Push basi (versi berubah) atau penerima tidak berhak lagi tidak dikirim
[lulus] Penerima: pembimbing sah, murobi berpenugasan, admin, atau HANYA wali pengaju (bukan seluruh wali santri)
[lulus] Wali pengaju diperiksa: akun aktif ber-role orang tua, data wali aktif, relasi santri aktif
[lulus] Pusat notifikasi web membuka rincian V7 (yang memeriksa ulang hak)

=== T-5. Laporan ===
[lulus] Kartu, daftar, dan ekspor memakai satu pembangun WHERE dan FROM yang sama
[lulus] SQL laporan tidak membaca alasan, catatan, atau alasan keputusan
[lulus] Cakupan di SQL: tidak dikenal → 1 = 0; pembimbing sah; relasi wali aktif
[lulus] Cakupan dihitung ulang dari basis data; parameter peran hanya memilih peran yang dimiliki
[lulus] Ekspor diaudit dan aman spreadsheet
[lulus] Rute API laporan dan ekspor
[lulus] Halaman laporan memakai penjaga V7 (no-store) dan keluaran ter-escape
