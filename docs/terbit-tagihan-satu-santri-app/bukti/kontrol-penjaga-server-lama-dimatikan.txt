
=== A-1. Petugas: rincian tarif = API ===
[lulus] Rincian santri (petugas): tombol "Terbitkan tagihan" tampil
[lulus] API pratinjau satu santri: satu baris, total Rp300.000
[lulus] Layar = API: Syahriah Rp150.000, Makan Rp200.000, potongan −Rp50.000, total Rp300.000

[lulus] Rincian tarif: tanpa gulir horizontal pada 375 px (selisih 0px)

[lulus] Tepat satu tagihan Rp300.000 untuk santri ini; santri SMP lain tidak ikut
