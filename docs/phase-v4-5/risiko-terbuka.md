# Risiko terbuka Fase 5

- **Belum siap rilis.** Audit Claude Code belum dilakukan. iOS runtime tidak terverifikasi (CoreSimulator timeout); Android hanya emulator smoke guru/wali, bukan mutasi lengkap semua peran/perangkat fisik. IPA/APK distribusi, Safari, pembaca layar, fontScale native besar, beban besar dan UAT belum dibuktikan.
- Push provider/APNs/FCM/Expo dan receipt nyata tidak dijalankan. Mock ON/OFF serta URI Android bukan bukti ketukan push fisik/cold-start notifikasi. Penting: pointer baseline adalah `tipe=rapor`, bukan `v4_rapor`; validator dan tombol InApp kini diselaraskan dan regresinya ada.
- Apache 2.4.67 lokal menguji FilesMatch dan blok direktori dengan file sintetis. cPanel/Apache/FastCGI nyata, AllowOverride, PHP handler, CDN/WAF/access/body log, batas upload dan forwarding Authorization tetap menunggu smoke.
- PHP 8.4.14/MariaDB 12.3.2 lokal berbeda dari MariaDB hosting 10.6.24. CHECK, lock/gap SERIALIZABLE selama render PDF, beban dan 4× innodb_lock_wait_timeout tetap memerlukan uji lingkungan tujuan. Nol pertemuan tetap mengikuti keputusan Fase 3; tidak membuat Alpa sintetis.
- Database/filesystem tidak atomik. Restore lokal dan injeksi korupsi lulus; putus jaringan nyata tepat COMMIT, power/disk loss, fsync direktori, backup/restore/durability hosting belum. Rekonsiliasi read-only, tidak membersihkan orphan otomatis. Snapshot dan backup memuat tanda tangan/PDF privat.
- Tarik/Ganti/Buka semester nonaktif tetap dibatasi kontrak Fase 4; kebutuhan penarikan historis memerlukan keputusan Human Developer. Tidak menambah bypass administratif. Target 81.00/75.00 tetap format snapshot lama.
- Wali maksimum 200 rapor; opsi/matriks/riwayat belum pagination/benchmark kelas besar. PDF dibaca utuh di memori sebelum sharing. Ukuran besar dan OS membatalkan/kill saat share perlu diuji fisik; residu cache dibersihkan saat startup/logout, tidak menjamin penghapusan sebelum proses yang dihentikan dibuka kembali. Unduhan yang sengaja disimpan pengguna di luar sandbox tidak dihapus aplikasi.
- Log HTTP/Metro dan audit V4 serta payload outbox diperiksa lokal. Log OS/provider/proxy/analytics pihak ketiga belum. Tidak menambah telemetry. Backup/credential/token/PDF privat tidak dimasukkan ke bukti Git.
- Warisan `phase5_static` sebelumnya gagal path laporan mobile lama: diperbaiki ke rute nyata src/app/reports.tsx dengan assertion laporan/cetak yang sama. Statis V2/V3 disesuaikan ke helper validator baru; unit test membuktikan jenis/ID valid dan penolakan ID tak sah. Tidak menghapus assertion, menonaktifkan verifier atau membersihkan residu DB.
- Kegagalan harness awal: .env.example terlewat saat menyalin sandbox; flag V3/DB wajib menyebabkan exit 77 pada pengulangan; keduanya dilengkapi lalu semua 15 statis exit 0. Ringkasan awal dipertahankan di regresi-ringkasan.txt, final di statis-final.txt. Tidak menyamakan 77 dengan lulus.
- Uji browser awal menemukan cache Metro/alamat API lama; satu login akun sintetis mencoba endpoint konfigurasi lama. Setelah itu seluruh uji memakai salinan tanpa dotenv, cache baru dan penjaga origin localhost. Kegagalan modal akibat animasi diperbaiki pada penantian harness. Client Android lama gagal modul native, kemudian debug client dibangun ulang. Tidak mengklaim kegagalan awal sebagai hasil lulus.
- Tidak merge/deploy/migrasi produksi, mengirim rilis, mengubah kanal produksi, menjalankan Claude bersamaan atau mengerjakan PRD berikutnya. Operator masih harus melaksanakan checklist, menetapkan restore point/rilis aktual dan memberi persetujuan sesudah audit.
